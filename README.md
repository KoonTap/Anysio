# ANYSIO — ระบบนัดหมายคลินิกสัตว์เลี้ยง

เว็บสำหรับเจ้าของสัตว์ เจ้าหน้าที่ต้อนรับ สัตวแพทย์ และผู้ดูแลระบบ พัฒนาด้วย Node.js, Express, EJS และ PostgreSQL แยกโค้ดตาม MVC

กระบวนการหลัก: เจ้าของเพิ่มสัตว์และขอนัด → เจ้าหน้าที่ยืนยันและเลือกแพทย์ → เช็กอิน → แพทย์บันทึกผล → เจ้าของดูผลตรวจ หรือเจ้าหน้าที่ปฏิเสธ/เจ้าของยกเลิกนัดตามสถานะที่อนุญาต

## ติดตั้งและเริ่มใช้งาน

สภาพแวดล้อมที่ตรวจสอบล่าสุด: Node.js 24.21.0 และ PostgreSQL 18.6

1. ติดตั้ง Node.js และ PostgreSQL แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์
2. ติดตั้งไลบรารีตาม lockfile:

   ```sh
   npm ci
   ```

3. คัดลอก `.env.example` เป็น `.env` แล้วกำหนด `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` ให้ตรงกับ PostgreSQL ในเครื่อง ใช้ชื่อฐานข้อมูลใหม่สำหรับติดตั้งครั้งแรก
4. สร้างค่า Session Secret ของเครื่องด้วยคำสั่งต่อไปนี้ แล้วนำผลลัพธ์ใส่ `SESSION_SECRET` ใน `.env`:

   ```sh
   node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
   ```

5. สร้างฐานข้อมูลเปล่าตาม `.env` (บัญชี PostgreSQL ต้องมีสิทธิ์สร้างฐานข้อมูล) หรือสร้างเองผ่าน pgAdmin:

   ```sh
   node db/create.js
   ```

6. สร้างตารางและข้อมูลตัวอย่าง:

   ```sh
   npm run db:setup
   ```

   `db/schema.sql` กำหนดตารางและข้อจำกัด ส่วน `db/seed.js` สร้างข้อมูลตัวอย่าง คำสั่ง setup จะไม่เขียนทับเมื่อพบตาราง users อยู่แล้ว และไม่ได้เป็นคำสั่งรีเซ็ตสิทธิ์

7. เปิดเว็บ:

   ```sh
   npm start
   ```

   เข้าผ่าน `http://127.0.0.1:3000` หรือพอร์ตที่กำหนดใน `.env` ขณะพัฒนาใช้ `npm run dev` เพื่อให้เซิร์ฟเวอร์เริ่มใหม่เมื่อแก้ไฟล์

อย่าอัปโหลด `.env`, ข้อมูล Session หรือไฟล์แนบส่วนตัวขึ้น GitHub ไฟล์เหล่านี้ถูกยกเว้นไว้ใน `.gitignore` การ clone โค้ดจะไม่ได้คัดลอกข้อมูล PostgreSQL และไฟล์แนบจากเครื่องเดิม

## บัญชีตัวอย่างสำหรับฐานข้อมูลใหม่

บัญชีต่อไปนี้สร้างโดย `db/seed.js` และใช้รหัสผ่านตัวอย่าง `Anysio123!` ฐานข้อมูลเก็บเป็น bcrypt Hash

| บทบาท | ชื่อผู้ใช้ | หน้าที่ |
|---|---|---|
| Admin | `admin` | ทุกฟังก์ชันและส่วนจัดการระบบ |
| Owner | `owner`, `owner2` | จัดการสัตว์และนัดของตน ดูผลตรวจของสัตว์ตน |
| Receptionist | `reception` | ดูนัด ยืนยัน/ปฏิเสธ มอบหมายแพทย์ และเช็กอิน |
| Vet | `vet`, `vet2` | ดูนัดที่ได้รับมอบหมายและบันทึก/แก้ผลตรวจ |

บัญชีและสิทธิ์ในฐานข้อมูลที่มีการใช้งานแล้วอาจต่างจากข้อมูลตัวอย่าง ตารางสิทธิ์เริ่มต้นอยู่ใน `db/catalog.js`; สิทธิ์จริงโหลดจากฐานข้อมูลใหม่ทุกคำขอ

## จุดสำคัญสำหรับสาธิต

- `/app` และหน้าสัตว์/นัด ตรวจทั้ง Permission และเจ้าของข้อมูลหรือแพทย์ที่ได้รับมอบหมาย
- `/admin` และ `/api/admin` ใช้กฎเดียวกัน ผู้ไม่มีสิทธิ์เข้าผ่าน URL/API โดยตรงไม่ได้
- หน้า Role เพิ่ม แก้ไข และลบบทบาทได้ แต่ลบ Admin หรือบทบาทที่มีผู้ใช้ไม่ได้
- หน้า Permission เพิ่มรหัสฟังก์ชันที่ระบบรองรับได้ การเพิ่มชื่อใหม่อย่างเดียวไม่ได้สร้างฟังก์ชันใหม่
- หน้า ACL ให้/ถอนสิทธิ์แล้วมีผลกับ Session เดิมทันทีโดยไม่เริ่มเซิร์ฟเวอร์ใหม่
- ภาพแนบเป็น JPG/PNG ไม่เกิน 5 MB ตรวจเนื้อหาภาพจริง และจำกัด 25 ล้านพิกเซล
- เปิดภาพผ่าน `/app/files/:id` และดาวน์โหลดผ่าน `?download=1`; ไฟล์ไม่เปิดเป็น public
- Log เก็บใน PostgreSQL และกรองวันที่ไทย ผู้ใช้ และเหตุการณ์ได้
